# Vocabular

PWA для изучения английских и испанских слов по чек-листу (переключатель EN/ES в шапке):

1. Значение (Google)
2. Произношение (аудио + YouGlish)
3. Объяснение и пример
4. Похожие слова (синонимы)
5. Другие значения
6. История и происхождение (Wiktionary / Etymonline)
7. Слово в действии — Playphrase.me

Изученные слова сохраняются в личный словарь (локально на устройстве, `localStorage`).

## Запуск локально

```bash
python3 -m http.server 8899
# открыть http://localhost:8899
```

## Технологии

- Чистый HTML/CSS/JS, без сборки и зависимостей
- [Free Dictionary API](https://dictionaryapi.dev) — определения, транскрипция, аудио, синонимы
- Wiktionary API — этимология
- Service worker + manifest — установка на домашний экран и офлайн-оболочка

## Установка на телефон

Нужен хостинг с HTTPS (GitHub Pages, Netlify, Vercel — бесплатно).
После этого на iPhone: Safari → «Поделиться» → «На экран "Домой"».
